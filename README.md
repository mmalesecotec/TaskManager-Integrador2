# TaskManager-Integrador2
Actividad Integradora 2 - Gestor de tareas con JavaScript
Descripción del proyecto
Es una aplicación web que permite organizar y administrar tareas personales. El proyecto fue desarrollado utilizando HTML, CSS y JavaScript, aplicando conocimientos adquiridos en clase
Objetivo
Desarrollar una aplicación web que permita registrar, consultar, modificar y eliminar tareas, utilizando JS para manipular la información del sitio y almacenar la información en el navegador
Funcionalidades
- Agregar tareas y prioridad
- Editar tareas y priridad
- Eliminar tareas y prioridad
- MArcar tareas como completadas, pendientes
- Filtar tareas por su estado
- Buscar tareas
- Ordenar tareas
- Mostrar resumen de tareas mediante un dashboard.
- Consultar tareas API públicas
- Guardar y recuperar tareas mediante LocalStorage
- Validar tareas sin nombre o duplicadas
Tecnología utilizada
HTML, CSS3, JS, ES6, LocalStorage, Fetch API, JSONPlaceholder, Git y GitHub
Archivos Principales
index.html / styles.css / script.js / utilidades.js / README.md
Cómo ejecutar la aplicación
1.- Descargar o clonar el repositorio de GitHub
2.- Abrir la carpeta del proyecto en un editor de código
3.- Ejecutar index.html mediante un servidor local (Live Server)
4.- Abrir la dirección local generada en el navegador
* Se recomienda utilizar un servidor local pq la aplicación emplea módulos JavaScript ES6.
Pruebas realizadas
LAs pruebas que se realizaron fueron: registro, edición, eliminación, búsqueda, filtros, ordenamiento y consulta de la API; se probo además que el LocalStorage conserva las tareas y sus modificaciones despues de actualizar la página (F5).
Conclusión
El desarrollar esta página me peermitió aplicar conocimeintos adquiridos en clase más los que consultaba en el tiempo de desarrollo.
Se utilizaron eventos, manipulación del DOM, arreglos, funciones, validaciones, módulos ES6, consumo de API y almacenamiento local para construir un Administrador de Tareas.
